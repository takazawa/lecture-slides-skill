# デザインの決まり

`slides/deck.css` の使い方。値は CSS の変数にある。HTML に色コードを直に書かない。

## 色（3 層）

| 層 | 色 | 使うところ | 使わないところ |
| --- | --- | --- | --- |
| 地 | 紫紺 `--shikon`、灰色（`--ink` `--sub` `--muted` `--line`） | 見出し、用語、強調（`<em>`）、罫線、番号 | — |
| 役割色 | 橙 `.ra`、青緑 `.rb`、紫紺 `.rc` | 式の部品と、その説明を同じ色で結ぶ | 飾り、ただの強調、見出し |
| 赤ペン | `--pen`（`.pen` `.circ` `.num`） | 画面の絵・式・表への注記。授業で書き込むのと同じ見た目 | 役割色の代わり、本文の強調 |

画面の絵（`.win`）とグラフ（SVG）の中は、本物に似せるための色を使ってよい。

### 役割色の決まり

式に 2〜3 個の部品があり、それぞれに「どこから」「初項」のような役目の名前があるときに使う。

```html
<div class="disp">$\displaystyle \sum_{\ra{k=1}}^{\rb{t}} \rc{a_k} = a_1 + \cdots + a_t$</div>
<li><span class="ra">下の $k = 1$</span>: どこから</li>
<li><span class="rb">上の $t$</span>: どこまで</li>
<li><span class="rc">右の $a_k$</span>: 何を足すか</li>
```

- 式の側（`\ra{…}`）と説明の側（`class="ra"`）の両方に付ける。片方だけなら使わない（機械チェック 14 が拾う）。
- 1 枚に 3 色まで。同じ回の中で、同じ役目には同じ色を通す（初項は橙、公比は青緑、のように）。
- 色だけに頼らない。説明の側には必ず役目の名前を言葉で書く（白黒で刷っても読める）。
- 役割色を使うページでは、`<em>` の強調を減らす（紫紺が役割色 3 と紛れる）。
- グラフで系列が複数あるときも、線の色と凡例・本文の言葉を同じ役割色でそろえる。
- 部品が 1 つだけ、または 4 つ以上なら色ではなく別の見せ方にする（赤ペンの丸囲み、表）。

向いている例: Σ の下端・上端・足すもの／等比数列の和の初項・公比・項数／$y = ax + b$ の傾きと切片／費用の式の固定費と変動費／期待値の「値」と「確率」。

## 文字

| 用途 | 大きさ | クラス |
| --- | --- | --- |
| 題 | 38px | `h2` |
| ゴール・まとめ | 40px | `.big-list` |
| 本文 | 28px | 既定 |
| 少し小さい本文・用語 | 24〜26px | `.small` `.terms` |
| 表 | 22〜24px | `table.tbl` |
| 補足・出典 | 20px | `.note` `.cap` |
| 画面の絵の中 | 15〜22px | `.win` |

- 太さは 400 と 600 だけ。
- 本文を 22px より小さくして詰めない。入らなければページを分けるか、話題を減らす。14px 未満は機械チェックが落とす。
- 主役の式は `.disp`（34px）。その回でいちばん大事な式は `.disp.lg`（44px）。

## 枠と並べ方

- 枠（`.win` `.step`）を横に並べるときは `.flow.same`（幅と高さがそろう）、2 列で段をそろえるときは `.grid2`。
- 強調する箱は `.step.on`。ふちの色だけが変わり、大きさは変わらない。
- 用語の定義は箱に入れず、`.terms`（罫線で区切る）。表の見出しは塗らない。
- 影・角丸は `.win` だけ。影は画面でだけ描き、PDF では消す（`deck.css` の `@media print`。影は PDF で灰色の四角に化けるビューアがある）。回の CSS で `box-shadow`・`filter`・半透明の重ね塗りを足さない。グラデーション・飾りのアイコン・色付きの帯の見出しは使わない。
- 余白は 4px の倍数。

## 余白（書き込む資料のとき）

PDF をタブレットのノートアプリに入れて、授業中に書き込む使い方を想定している。書き込まない資料（配るだけ・投影するだけ）なら、空きは文字と図を大きくして埋める。

- 例題・演習のページは、問題文を上に置き、下を空ける。
- 表の「解く欄」は空欄の行・列にする。
- 補足（`.note`）は下端に固定されるので、本文との間が書き込む場所になる。

## 画面の絵

ターミナル・エディタ・ブラウザ・GitHub・Excel は、スクリーンショットではなく `.win` の部品で描く。1 枚に 1 つを大きく。注記は赤ペンで、絵の中に書く。
